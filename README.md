# QST Desktop for Windows

This repository contains the official public Windows installer and release notes for **QST Desktop**, the optional companion to [QST Listing Workspace for Shopify](https://apps.shopify.com/qst-listing-workspace).

## Download

**[Download QST Desktop v1.0.5](https://github.com/q-marx/qst-desktop-releases/releases/download/v1.0.5/QST-Setup-v1.0.5.exe)**

[View the latest release notes and checksum](https://github.com/q-marx/qst-desktop-releases/releases/latest)

## What QST Desktop does

- Pairs with QST Listing Workspace.
- Lets the seller review and edit listing information locally.
- Creates reusable marketplace packs.
- Publishes one selected product or a selected batch directly to eBay after setup.
- Keeps publishing seller-controlled.

QST does **not** automatically synchronise inventory or orders, and it does not write changes back to the Shopify catalogue.

## Requirements

- Windows
- QST Listing Workspace installed on a Shopify store
- For direct eBay publishing: an eBay seller account, business policies, dispatch location and category settings
